# App Store 등록 문구 (한국어)

## 홍보 문구 (Promotional Text, 170자 이내)

사진 못 찍어도 괜찮아요. 격자·수평·인물 배치를 실시간으로 잡아주고, AI가 더 나은 구도까지 추천해 드려요. 셔터만 누르면 인생샷 완성!

## 설명 (Description, 4000자 이내)

"찍어준 사진마다 왜 이래…" 소리 듣는 똥손을 위한 촬영 보조 카메라입니다.

똥손카메라는 촬영하는 순간 화면 위에서 직접 알려줍니다. 어디에 사람을 세워야 하는지, 카메라가 기울었는지, 얼마나 다가가야 하는지 — 감이 아니라 가이드로 찍으세요.

■ 실시간 촬영 가이드
• 격자와 수평계: 화면이 기울면 바로 알려주고, 수평이 맞으면 "좋아요" 표시
• 인물 배치 가이드: 인물을 자동 인식해 위치와 크기를 안내
• 잘림 경고: 머리나 발이 화면에서 잘리면 촬영 전에 미리 경고
• 머리 공간·각도·줌 힌트: 답답하거나 휑한 사진이 되지 않도록 적정 여백과 거리를 안내

■ AI 구도 추천
• 지금 화면을 분석해 더 나은 구도를 제안
• 미니맵과 타겟 가이드가 "어느 방향으로 얼마나 움직일지" 알려줘서 따라 하기만 하면 됩니다

■ 포즈 추천
• 뭘 해야 할지 모르는 손과 시선을 위해, 상황에 맞는 포즈를 골라 화면에 겹쳐 보여줍니다

■ 감성 무드
• 찍은 사진에 무드를 입혀 바로 저장 — 갤러리로 자동 저장됩니다

■ 커뮤니티
• 내가 건진 인생샷을 공유하고, 다른 사람들은 어떻게 찍었는지 구경하세요

이런 분께 추천합니다
• 연인·친구 사진을 찍어줄 때마다 눈치 보이는 분
• 여행 가서 남는 건 사진뿐인데, 남는 사진이 없는 분
• 구도·수평·비율… 이론은 됐고 그냥 잘 찍고 싶은 분

카메라를 들면 앱이 알려주고, 셔터만 누르면 됩니다. 오늘부터 똥손 탈출!
