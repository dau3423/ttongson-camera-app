# 똥손카메라 (Butterfingers Camera) 개발 기획서

- **작성일**: 2026-07-02
- **문서 유형**: 개발 기획서 (구현용)
- **상태**: 설계 확정, 구현 계획 수립 전

---

## 1. 개요

### 1.1 한 줄 정의
사진을 잘 못 찍는 사람("똥손")을 위해, **카메라 프리뷰 화면에서 실시간으로 구도·각도·줌·인물 배치를 가이드**하고, 필요할 때 **AI가 더 나은 구도를 추천**해주는 촬영 보조 앱.

### 1.2 문제 정의
- 대부분의 사람은 "좋은 사진의 규칙"(수평, 3분할, 머리 공간, 촬영 각도)을 모른 채 촬영한다.
- 찍고 난 뒤에야 "기울었다 / 잘렸다 / 답답하다"를 깨닫지만 이미 늦었다.
- 기존 카메라 앱의 격자선은 정적일 뿐, **"지금 어떻게 고쳐야 하는지"를 알려주지 않는다.**

### 1.3 핵심 가치
> **촬영하기 전에, 실시간으로, 무엇을 어떻게 고쳐야 하는지 알려준다.**

### 1.4 타겟 사용자
- 카메라 앱 기본 기능만 쓰는 일반 사용자
- 인물/여행 사진을 자주 찍지만 결과물이 늘 아쉬운 사람
- 구도·사진 이론을 배우고 싶지 않고, 그냥 잘 나오길 원하는 사람

## 2. 기술 스택

| 영역 | 선택 | 비고 |
|---|---|---|
| 프레임워크 | **Flutter** | 프리뷰 위 실시간 오버레이 렌더(CustomPaint)에 유리, 크로스플랫폼 |
| 카메라 | `camera` 플러그인 | 프리뷰 + image stream (프레임 스트림) |
| 온디바이스 AI | `google_ml_kit` (Pose/Face Detection) + MediaPipe | 실시간, 네트워크 불필요 |
| 센서 | `sensors_plus` | accelerometer/gyroscope로 기울기·수평 산출 |
| 오버레이 렌더 | Flutter `CustomPaint` | 격자·수평계·포즈 힌트 |
| 클라우드 AI | 비전/멀티모달 LLM API (온디맨드) | 고급 구도 추천 |
| 저장 | 기기 갤러리 | 촬영 결과 저장 |

> AI 방식은 **하이브리드**: 실시간 가이드는 전부 온디바이스, 고급 구도 추천만 클라우드.

## 3. 아키텍처

```
[카메라 프리뷰]
      │ (프레임 스트림 ~15fps)
      ▼
[온디바이스 분석 엔진]  ── 실시간(매 프레임/샘플링)
  ├ 수평/기울기      (센서: accelerometer/gyroscope)
  ├ 포즈·인물 감지    (ML Kit Pose/Face Detection)
  └ 구도 지표 계산    (3분할 교차점, 여백, 머리 공간, 수평선)
      │
      ▼
[가이드 오버레이 렌더러] ── CustomPaint로 격자·수평계·포즈 힌트 표시
      │
      ├──(사용자가 '구도 추천' 탭 또는 2초 정지)──▶ [클라우드 AI Advisor]
      │                                            (프레임 1장 전송 → 구도 제안 텍스트/화살표)
      ▼
[촬영 버튼] → 갤러리 저장
```

### 3.1 모듈 분리 (4개 핵심 유닛)

각 모듈은 하나의 명확한 책임을 가지며, 잘 정의된 인터페이스로 통신하고, 독립적으로 테스트 가능하다.

#### 모듈 1: `CameraService` (카메라 래퍼)
- **하는 일**: 카메라 초기화, 프리뷰 위젯 제공, 프레임 스트림 방출, 촬영·저장.
- **인터페이스**:
  - `Stream<CameraFrame> get frameStream`
  - `Future<File> capture()`
  - `Widget get previewWidget`
- **의존**: `camera` 플러그인, 기기 갤러리.

#### 모듈 2: `AnalysisEngine` (온디바이스 분석)
- **하는 일**: 프레임 + 센서 데이터를 받아 실시간 구도 지표(`GuideMetrics`)를 산출.
- **인터페이스**:
  - `Stream<GuideMetrics> analyze(Stream<CameraFrame> frames)`
- **산출물 `GuideMetrics`**: 기울기 각도, 수평 편차, 감지된 인물 bounding box·포즈 랜드마크, 3분할 정렬 점수, 머리 공간 비율.
- **의존**: `sensors_plus`, `google_ml_kit`.

#### 모듈 3: `GuideOverlay` (가이드 렌더러)
- **하는 일**: `GuideMetrics`를 받아 프리뷰 위에 시각 가이드를 그린다. 판단 로직 없음(순수 렌더).
- **인터페이스**: `Widget build(GuideMetrics metrics)`
- **의존**: Flutter `CustomPaint`.

#### 모듈 4: `CloudAdvisor` (클라우드 고급 추천)
- **하는 일**: 온디맨드로 프레임 1장을 클라우드 AI에 보내 구도 제안을 받아 반환.
- **인터페이스**: `Future<CompositionAdvice> suggest(CameraFrame frame)`
- **산출물 `CompositionAdvice`**: 자연어 조언 + 방향 힌트(예: "왼쪽으로 조금, 살짝 낮은 각도").
- **의존**: 비전/멀티모달 LLM API.

### 3.2 데이터 흐름
1. `CameraService`가 프레임 스트림 방출.
2. `AnalysisEngine`이 프레임+센서를 소비해 `GuideMetrics` 스트림 산출(성능 위해 프레임 샘플링).
3. `GuideOverlay`가 최신 `GuideMetrics`로 화면 갱신.
4. 사용자가 추천을 요청하거나 카메라가 2초간 정지하면 `CloudAdvisor` 호출.
5. 촬영 시 `CameraService.capture()` → 갤러리 저장.

## 4. 기능 명세

### 4.1 격자·수평 가이드 (Phase 1)
- **3×3 격자**: 3분할 구도용 격자 상시/토글 표시.
- **수평계**: 센서 기반 기울기 실시간 표시. 수평(±1.5°) 진입 시 선이 녹색으로 스냅되고 미세 진동 피드백.
- **기울기 보정 안내**: "왼쪽을 살짝 내리세요" 같은 방향 화살표.
- **성공 기준**: 기울기 오차 실시간 표시 지연 < 100ms, 수평 판정 정확.

### 4.2 인물 포즈·위치 가이드 (Phase 1)
- **인물 감지**: ML Kit로 사람 bounding box·얼굴 감지.
- **머리 공간(headroom)**: 머리 위 여백이 과다/과소면 "카메라를 살짝 올리세요/내리세요".
- **잘림 경고**: 발/머리/손이 프레임에 잘리면 경고.
- **3분할 정렬**: 인물(또는 얼굴)이 3분할 교차점에 가깝게 오도록 이동 힌트.
- **성공 기준**: 1명 기준 감지·힌트가 프리뷰에서 부드럽게(끊김 최소) 동작.

### 4.3 각도·줌 가이드 (Phase 1)
- **촬영 각도**: 센서로 기기 피치(높이/내려다봄/올려다봄) 추정, 상황별 권장 각도 안내(예: 인물은 눈높이~약간 위).
- **줌 안내**: 인물 크기 대비 권장 줌 배율 힌트(너무 멀면 "조금 당기세요").
- **성공 기준**: 각도·줌 힌트가 상황(인물/풍경)에 맞게 표시.

### 4.4 AI 구도 추천 (Phase 2, 클라우드)
- **트리거**: 사용자가 "구도 추천" 버튼 탭, 또는 카메라 2초 정지 감지 시 자동.
- **동작**: 현재 프레임 1장을 클라우드 AI로 전송 → 장면(인물·배경·위치) 분석 → "이렇게 찍으면 좋아요" 자연어 제안 + 방향 힌트 오버레이.
- **UX**: 로딩 인디케이터, 실패 시 온디바이스 가이드로 폴백. 결과는 카드/오버레이로 표시.
- **성공 기준**: 요청→응답 체감 지연 목표 < 3초, 실패 시 앱 흐름 방해 없음.

## 5. 개발 단계 (Phasing)

MVP에 4개 기능을 모두 포함하되, 온디바이스 실시간 가이드를 먼저 완성해 앱을 단독 동작 가능 상태로 만든 뒤 클라우드 추천을 얹는다.

| Phase | 범위 | 산출물 |
|---|---|---|
| **Phase 0** | 프로젝트 세팅, `CameraService` 프리뷰+촬영+저장 | 사진 찍고 저장되는 최소 앱 |
| **Phase 1** | 격자·수평, 포즈·위치, 각도·줌 (온디바이스 전부) | 네트워크 없이 동작하는 실시간 가이드 앱 |
| **Phase 2** | `CloudAdvisor` AI 구도 추천 | 고급 추천까지 포함한 MVP 완성 |

## 6. UX / 화면

- **메인 = 카메라 화면 하나**로 단순화. 설정은 최소.
- 프리뷰 위 오버레이: 격자(토글), 수평계(상단/중앙), 인물 힌트(화살표·박스), 각도·줌 힌트(하단).
- 하단: 촬영 버튼(중앙), 구도 추천 버튼, 격자 토글.
- 가이드는 **방해되지 않게** — 색·투명도로 상태만 직관 전달(빨강=고쳐라, 녹색=좋다).

---

## 7. 비기능 요구사항

- **성능**: 실시간 가이드 프레임 처리로 프리뷰 프레임 드랍 최소화(프레임 샘플링·스로틀링 적용).
- **프라이버시**: 온디바이스 분석은 전송 없음. 클라우드 추천 시 **프레임 전송을 사용자에게 명확히 고지·동의**. 이미지 서버 보관하지 않음(요청 처리 후 폐기).
- **오프라인**: Phase 1 기능은 네트워크 없이 완전 동작.
- **접근성**: 색약 고려(색 + 아이콘/텍스트 병행).

---

## 8. 범위 밖 (Out of Scope, MVP 기준)

- 사진 후보정/필터/편집
- 동영상 촬영 가이드
- 다중 인물(2명+) 정밀 배치 최적화 (1명 우선, 다인원은 기본 감지까지만)
- 소셜 공유, 계정/로그인
- 촬영 이력/갤러리 관리 화면

| "가이드가 잔소리처럼 느껴짐" | 표시 최소화·토글 제공, 상태색 위주의 조용한 피드백 |

## 10. 성공 지표 (MVP)

- 사용자가 가이드를 따랐을 때 수평·3분할·머리공간이 기준 내로 개선되는 비율.
- "촬영 전 가이드 → 촬영" 완료율.
- AI 추천 사용 시 만족도(정성 피드백).
