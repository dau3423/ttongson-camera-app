# Handoff: 똥손 카메라 — 촬영 화면 재설계 (+ 로그인/회원가입/커뮤니티/팝업)

## Overview
"똥손카메라"는 촬영 **전에** 실시간으로 "무엇을 어떻게 고칠지"를 한 번에 한 가지씩 코칭해 초보(똥손)도 좋은 구도의 사진을 찍게 하는 카메라 앱입니다. 이 핸드오프는 촬영 화면을 기존 Flutter 코드(`lib/screens/camera_screen.dart`, `lib/overlay/*`, `lib/cloud/*`)의 실제 기능에 충실하게 **재설계**한 결과와, 함께 만든 로그인·회원가입·커뮤니티·프로필·시스템 팝업 화면을 담습니다.

## About the Design Files
이 번들의 `똥손 카메라.dc.html` / `Phone.dc.html` 은 **HTML로 만든 디자인 레퍼런스**입니다 — 의도한 모습과 동작을 보여주는 프로토타입이며, 그대로 복붙할 프로덕션 코드가 아닙니다.
작업 목표는 이 HTML 디자인을 **기존 Flutter 코드베이스에 그 환경의 패턴(위젯 트리, `CustomPainter` 오버레이, 상태관리)으로 재현**하는 것입니다. 촬영 화면은 이미 `camera_screen.dart` + 오버레이 위젯들이 존재하므로, **새로 만들기보다 기존 위젯의 시각/레이아웃을 이 레퍼런스에 맞춰 조정**하세요.

## Fidelity
**High-fidelity (hifi)** — 최종 색/타이포/간격/인터랙션까지 확정된 목업입니다. 색상·크기·상태 전환을 이 문서의 토큰대로 픽셀 단위로 맞추되, 렌더링은 Flutter 위젯/`CustomPainter`로 구현합니다. (HTML의 SVG 아이콘은 Flutter의 `Icons.*` 또는 커스텀 페인터로 대체)

## 실제 코드와의 매핑 (중요)
재설계는 아래 실제 파일의 개념을 그대로 따릅니다:
- `lib/models/shooting_mode.dart` — `enum ShootingMode { person, nature, object }`, wire = `person/nature/object`. UI 라벨은 **인물 / 자연 / 사물**. 모드 휠 순환 순서는 이 enum 순서(인물→자연→사물→…).
- `lib/overlay/mode_selector.dart` — **선택된 모드는 항상 가운데**, 양옆에 이웃 모드가 흐리게. (레퍼런스의 `‹ 인물 · [자연] · 사물 ›` 휠)
- `lib/overlay/guide_overlay.dart` + `lib/analysis/guide_step.dart` — **한 번에 한 단계** 안내(수평→크롭→거리→위치→헤드룸→각도→완료). 화면 상단 검은 pill로 현재 지시 1개만 표시, 완료 시 초록 "찍으세요!" 배지.
- `lib/cloud/advice_overlay.dart`, `target_guide_overlay.dart`, `advice_minimap.dart` — 클라우드 AI 구도 추천: 목표 위치 **고스트 박스 + 화살표 + 미니맵**(인물/사물), 자연 모드는 텍스트 조언 카드 위주.
- 수평계(level line): 수평이면 초록, 기울면 빨강 + 회전.

## Screens / Views

### 1. 촬영 화면 (Camera) — 핵심
같은 기능을 안내 강도만 달리한 3개 시안이 있으나 **하나의 화면**입니다. 프로덕션은 상태에 따라 이 요소들이 조건부로 나타나는 단일 화면으로 구현하세요.

- **Purpose**: 모드 선택 → 실시간 코칭(수평/구도/AI 목표) → 정렬 완료 시 촬영.
- **Layout** (기준 프레임 376×812, 세이프에어리어 상단 64 / 하단 홈인디케이터):
  - **프리뷰 영역**: `top:64 · bottom:158` (좌우 풀블리드), `object-fit: contain` 느낌의 레터박스. 배경은 실제 카메라 프리뷰.
  - **상단 바** (height 44, `top:64`, 좌우 padding 16): 좌측 = 커뮤니티 아이콘, 우측 = 카메라 전환 아이콘. 44×44 히트영역.
  - **단계 pill**: `top:112`, 중앙정렬. `background:rgba(0,0,0,0.85)`, `radius:22`, `padding:11px 18px`, 흰 글씨 16px/600. 지시문 1개.
  - **완료 배지** (pill 대체): 초록 `rgba(46,125,50,0.95)`, `radius:26`, "✓ 찍으세요!" 19–20px/700 흰색.
  - **미니맵**(인물/사물, AI on): `top:118 · right:12`, 90×160, `bg:rgba(0,0,0,0.45)`, `radius:8`. 현재 피사체 박스(회색) → 목표 박스(앰버) + 화살표.
  - **AI 조언 카드**: `left/right:16 · bottom:170`, `bg:rgba(0,0,0,0.87)`, `radius:12`, `padding:14px 16px`. 별 아이콘 + 헤드라인 15/700 + 이유 12px 60% 흰색 + 닫기 ✕.
  - **줌 pill**: `bottom:150` 중앙, `rgba(0,0,0,0.55)`, "1.0x" 모노 13px.
  - **모드 휠**: `bottom` 클러스터 상단. 중앙 선택 라벨 앰버 20px/700, 이웃 라벨 흰색 45% 15px, 양끝 화살표 ‹ ›. 좌우 탭으로 순환.
  - **하단 컨트롤** (`bottom:40`, 좌우 padding 30): 좌 = 갤러리 아이콘(44), 중앙 = 셔터(72, 원형), 우 = [AI 토글, 격자 토글] 아이콘 40씩.
- **오버레이(프리뷰 위, 좌표는 프리뷰 영역 기준)**:
  - **3분할 격자**: 흰선 `rgba(255,255,255,0.35~0.5)`, 1px, 1/3·2/3 위치.
  - **수평선(level)**: 중앙, 길이 120–150 × 3px, `radius:3`. 수평=`#69F0AE`+glow, 기울기=`#FF5252`+`rotate(-7deg)`.
  - **AI 목표 고스트 박스**(인물/사물): 3px `#FFC107` 테두리 + `rgba(255,193,7,0.14)` 채움, `radius:10`. 현재→목표로 향하는 앰버 화살표(끝 마커), 시작점 흰 점.
  - **정렬 완료 시**: 목표 박스가 `#69F0AE` + `rgba(105,240,174,0.15)` 로 전환, 셔터가 초록 발광(`readyglow` 1.6s).

### 2. 로그인 (Login)
- 다크 라디얼 배경, `padding:96/30/40`. 타이틀 "다시 오셨네요" 30/700, 서브 14px 50%.
- 이메일/비밀번호 입력(라벨 모노 11px 앰버). 비밀번호 표시 토글(👁). 인라인 유효성 에러(`#FF6B6B` 12.5px).
- 기본 CTA "로그인" 앰버 배경/검정 글씨 16/700 radius 12.
- 소셜: Apple / 카카오 아웃라인 버튼. 하단 "회원가입" 링크.
- 성공 시 전체화면 오버레이(📷 원형 앰버 + "환영합니다!" + CTA).

### 3. 회원가입 (Signup)
- 닉네임/이메일/비밀번호(8자 이상) + 약관 동의 체크박스(체크 시 앰버). 검증: 빈값/8자 미만/미동의 각각 에러 문구. 성공 시 🎉 완료 오버레이.

### 4. 커뮤니티 (Community feed)
- 헤더 "촬영 팁" + [인기]/[최신] 탭. 카드: 아바타·닉네임·핸들·모드 태그(앰버 아웃라인)·⋯ 메뉴, 사진(170px, radius 14), 한줄 리뷰, 좋아요(♥ 토글, 카운트 증감)·댓글 수.
- ⋯ → **액션 시트**(하단 슬라이드업): 신고하기/차단하기(빨강) + 취소. 선택 시 확인 다이얼로그 → 확정 시 스낵바 토스트.

### 5. 프로필 (Profile)
- 앰버 커버 + 원형 이니셜 아바타, 이름/핸들/바이오, 통계(촬영·팁·팔로워), 3열 갤러리 그리드, 로그아웃(빨강 아웃라인 → 로그아웃 확인 팝업).

### 6. 메시지 박스 & 팝업 (System dialogs)
7종: 카메라 권한(중립), **AI 구도추천 프레임 전송 동의**(중립, 개인정보 고지), 저장 완료(단일버튼), 사진 삭제/게시물 신고/사용자 차단/로그아웃(파괴적, 강조버튼 레드).
- 다이얼로그: 중앙 모달 `bg:#1c1e22` radius 22, 상단 원형 아이콘, 타이틀 19/700, 본문 14px 60%, 하단 버튼 1~2개. 파괴적 액션의 강조 버튼은 `#FF3B30`, 중립은 앰버.
- 성공 결과는 하단 스낵바 토스트(흰 알약, 1.6–1.8s 후 소멸).

## Interactions & Behavior
- **모드 휠**: 좌우 탭/스와이프로 순환(person↔nature↔object), 선택 모드는 항상 중앙 고정.
- **격자 토글 / AI 토글 / 카메라 전환**: 하단·상단 아이콘. 전환 시 프리뷰 `scaleX(-1)` 미러(전면).
- **가이드 단계**: 정렬이 맞을 때까지 한 번에 한 지시. 모든 조건 충족 시 "찍으세요!" + 셔터 발광.
- **AI 목표 박스 색 전환**: 미정렬=앰버, 정렬완료=그린.
- **셔터**: 탭 시 화이트 플래시(0.18s) + 저장 스낵바 + 촬영 카운트 증가.
- **애니메이션**: `flashcap 0.18s`, `readyglow 1.6s`(완료 셔터), 시트 `sheetup 0.28s`, 팝업 `popin 0.28s`, 토스트 `toastup 0.2s`.

## State Management
촬영 화면 위주(기존 Flutter state/Provider에 매핑):
- `mode: ShootingMode` (person/nature/object)
- `gridVisible: bool`, `aiEnabled: bool`, `frontCamera: bool`
- `guideStep: GuideStep` / `ready: bool` — 현재 지시 및 완료 여부
- `level: bool`(또는 각도값) — 수평계 색/회전
- `shotCount: int`, `flash: bool`, `galleryOpen: bool`, `toast: String?`
- AI: `targetBox`, `personBox`, `adviceHead/adviceWhy`, 자연 모드는 목표 박스 없이 텍스트만.
- 온보딩/커뮤니티/팝업 state는 프로토타입 로직 클래스(`똥손 카메라.dc.html`의 `class Component`) 참고.

## Design Tokens
- **색상**
  - Accent(선택 모드·목표·CTA): `#FFC107`
  - Ready/수평/정렬/성공: `#69F0AE` (배지 배경 `rgba(46,125,50,0.95)`)
  - Warn/기울기: `#FF5252`
  - Danger(삭제·신고·차단·로그아웃): `#FF3B30` / 인라인 에러 `#FF6B6B`
  - 텍스트: `#f4f1ea`(주), `#e9e6df`(본문), 흰색 60–45% 보조
  - 표면: 앱 배경 `#0b0c0e`, 카드/모달 `#1c1e22`, 오버레이 검정 `rgba(0,0,0,0.85~0.87)`
- **타이포**: 한글 UI = Pretendard, 수치·라벨 = Space Mono, 대형 워드마크 = Space Grotesk. 크기: 타이틀 30, 섹션 24, pill 16, 본문 14, 라벨 11–13.
- **radius**: 입력/버튼 12, 카드 14, 모달 22, pill/배지 22–26, 미니맵/오버레이 8–10, 알약 100.
- **spacing**: 화면 좌우 패딩 24–30, 컴포넌트 간 16, 프리뷰 top 64 / bottom 158.
- **shadow**: 모달 `0 20px 60px rgba(0,0,0,0.6)`, 완료 셔터 glow `0 0 22px 5px rgba(105,240,174,0.6)`.

## Assets
- 아이콘은 인라인 SVG(사람/카메라전환/갤러리/별/격자)로 제작 → Flutter에서는 `Icons.*` 또는 커스텀 페인터로 대체 권장. 별도 이미지 애셋 없음.
- 프리뷰/썸네일은 CSS 그라디언트 플레이스홀더(실제 앱은 카메라 프리뷰·촬영 결과).
- 폰트는 Google Fonts / Pretendard CDN. 코드베이스의 기존 폰트 설정을 우선 사용.

## Files
- `똥손 카메라.dc.html` — 전체 프로토타입(촬영 3시안 · 로그인 · 회원가입 · 커뮤니티 · 프로필 · 팝업). 로직은 파일 내 `class Component`.
- `Phone.dc.html` — 재사용 iPhone 프레임(상태바/노치/홈인디케이터).
- `ref/` — 참고용으로 복사해 온 실제 Flutter 소스 일부(`camera_screen.dart`, `mode_selector.dart`, `guide_overlay.dart`, `shooting_mode.dart`, `advice_*`, `target_guide_overlay.dart`, 기획 스펙 `.md`). 재현 시 최우선 근거.

## 구현 순서 제안
1. `ref/`의 실제 소스와 기획 스펙으로 현재 위젯 구조 파악.
2. 촬영 화면 오버레이(격자·수평선·목표박스·미니맵·단계 pill·완료 배지)를 레퍼런스 토큰에 맞춰 정비.
3. 모드 휠·하단 컨트롤 레이아웃/아이콘/히트영역 정리.
4. 로그인·회원가입·커뮤니티·프로필·팝업을 코드베이스 라우팅/위젯으로 이식.
